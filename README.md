Portfolio Website Implementation Plan
Goal
Create a modern, responsive portfolio website using simple HTML, CSS, and JavaScript. The current 
index.html
 will be refactored into separate files and enhanced with better styling and functionality.

Proposed Changes
Structure
Split the single 
index.html
 file into:
index.html
: Main content structure.
style.css: All styling rules.
script.js: Interactive logic.
HTML (
index.html
)
Semantic structure: <header>, <main>, <footer>.
Sections:
Hero: Introduction / Welcome message.
About: Brief bio.
Skills: List of technical skills.
Projects: Showcase of work (Student Management System, etc.).
Contact: Contact information / form placeholder.
CSS (style.css)
Variables: Use CSS variables for easy theming (Dark/Light mode).
Layout: properties like Flexbox and Grid for responsiveness.
Typography: Clean, modern fonts (e.g., system fonts or Google Fonts if allowed, but sticking to system for simplicity as requested).
Responsiveness: Media queries for mobile devices.
JavaScript (script.js)
Theme Toggle: Switch between dark and light modes with local storage persistence.
Smooth Scrolling: For navigation links.
Dynamic Footer Year: Auto-update copyright year.
Verification Plan
Manual Verification
Open 
index.html
 in a web browser.
Check responsiveness by resizing the window.
Test the theme toggle button.
Click navigation links to verify smooth scrolling.
